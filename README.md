# CodSoft AI Internship Projects

This repository contains five Python projects completed as part
of my CodSoft Artificial Intelligence internship.

## Projects

### Task 1: Rule-Based Chatbot
A simple chatbot that responds to user inputs using predefined
rules, conditional statements, and pattern matching.

Technologies: Python, Regular Expressions

### Task 2: Tic-Tac-Toe AI
An AI opponent that plays Tic-Tac-Toe against a human using
the Minimax algorithm.

Technologies: Python, Game Theory, Minimax

### Task 3: Image Captioning AI
An image captioning application that generates textual
descriptions of images using a pretrained BLIP model.

Technologies: Python, PyTorch, Transformers, Pillow

### Task 4: Movie Recommendation System
A content-based recommendation system that suggests similar
movies using genre information and cosine similarity.

Technologies: Python, Pandas, Scikit-learn, TF-IDF

### Task 5: Face Detection System
A face detection application that detects faces in images
and webcam video using a pretrained Haar Cascade classifier.

Technologies: Python, OpenCV, Computer Vision
